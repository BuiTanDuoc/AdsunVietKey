Gõ tiếng Việt nhanh, nhẹ và chuẩn trên Windows.Type Vietnamese fast, light and right on Windows.

AdsunVietKey là bộ gõ tiếng Việt viết bằng C# / .NET 8, hoạt động theo cách UniKey quen thuộc: Telex, VNI, gõ tắt, chuyển mã, nằm gọn ở khay hệ thống. Không quảng cáo, không rườm rà.

AdsunVietKey is a Vietnamese input method written in C# / .NET 8. It works the way UniKey users expect: Telex, VNI, text macros and code conversion, living quietly in your system tray. No ads, no clutter.
